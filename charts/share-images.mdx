---
title: "Share chart images"
description: "Copy or download a chart as a PNG without making the chart public."
---

Use **Share image** to create a PNG from the chart data that is open in Chartbrew. Image sharing
does not enable public links or embeds, and it does not save the image settings.

## Create an image

1. Open the chart menu and select **Share chart**.
2. Select **Share image**.
3. Choose a size, theme, and background.
4. Show or hide the title, subtitle, logo, team name, project name, and Chartbrew branding.
5. Select **Copy image** or **Download image**.

You can use **Share image** while public sharing is off. Closing the window resets the image
options.

## Image sizes

- **Landscape** creates a 1280 × 720 image.
- **Mobile** creates a 1080 × 2340 image with a centered chart card.
- **Original** keeps the current chart aspect ratio and uses a higher output density within the
  image limits.

## Supported charts

Share image supports line, bar, horizontal bar, pie, doughnut, radar, polar, matrix, gauge, KPI,
and average charts. Table and markdown charts are not supported.

## Copy image requirements

Your browser must support PNG clipboard writes, and Chartbrew must use a secure connection. If the
browser blocks image access to the clipboard, use **Download image**.

## Data and privacy

The image uses the chart data that is open in your browser. Chartbrew does not save the generated
image or the temporary image settings. A private chart stays private when you create an image.

The project export permission controls access to image sharing. Chartbrew branding is selected by
default. You can select **White-label** to remove it.
